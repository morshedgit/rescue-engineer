# Quality, Architecture & Testing Standards

## Standards

1. **Code Cleanliness & Maintainability**:
   - Write modular, readable, and typed code where applicable.
   - Follow idiomatic patterns and conventions for the language and framework in use.
   - Keep functions focused and avoid deep nesting or excessive cyclomatic complexity.

2. **Error Handling**:
   - Implement graceful error handling with descriptive error messages.
   - Avoid empty catch blocks or silently swallowed errors.

3. **Validation & Testing**:
   - Every feature or fix should be accompanied by or validated against unit/integration tests.
   - Run linter/formatting checks before finishing any modification.
